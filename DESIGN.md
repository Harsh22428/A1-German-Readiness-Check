# Interface direction

The learner sits with a phone or laptop in a normally lit room after a lesson, possibly anxious about the exam; a bright readable surface and composed, supportive rhythm suit this task.

Use warm near-white surfaces, dark aubergine text, and a restrained plum accent. Use OKLCH variables and one system sans-serif family. Large start-screen heading, familiar controls and compact informational labels. Results use horizontal skill rows and numbered action plans rather than a decorative dashboard.

The application shell has a small typographic wordmark, stage navigation, a narrow task column and a quieter contextual rail on wide screens. Collapse the rail below content on mobile. No photography is needed: the meaningful visual is a small live preview of the assessment report, implemented in HTML/CSS. Raster image generation is skipped because it adds no task information.

Use 8px-based spacing with intentional larger section gaps, rounded controls, thin full borders and clear selected states. No gradients, glass, side-stripe callouts, fake metrics or decorative animation. Motion is limited to short state transitions and respects reduced motion.

This is an implementation choice within the approved PRD. It does not represent Globio's official brand system.
